# 📜 Changelog: HarmonyMind

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-07-25

### Added
- Created `src/` directory and restructured the Python scripts.
- Refactored `src/train_model.py` to support early stopping, checkpoints, validation metrics, baseline comparison, and evaluation charts.
- Fused real-time LIME text explainability and MediaPipe landmark calibration.
- Added `/telemetry/export` CSV export endpoint and `/telemetry/report` PDF compilation endpoints.
- Integrated Chart.js in `templates/index.html` to display Timeline, Frequency, and Heatmap charts.
- Created `docs/PROPOSAL.md`, `docs/LITERATURE_SURVEY.md`, and `docs/FINAL_REPORT.pdf` matching academic criteria.
- Programmatically generated 5 Jupyter Notebooks (`notebooks/`).
- Generated repository assets (`docs/architecture/architecture.png`).
